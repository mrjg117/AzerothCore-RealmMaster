# patches 目录

存放模组补丁文件。每个补丁以目标模组名作为子目录名，结构与模组目录一致。

## 目录结构

```
patches/
└── <模组名>/
    ├── src/          # 源码补丁
    └── *.conf.dist   # 配置文件补丁
```

## 补丁应用方式

build-patched.sh 在 `stage_modules()` 后调用 `apply_patches()`，将 patches/ 下各子目录的文件复制到 `src_path/modules/<模组名>/` 对应位置。

## 注意事项

- 子目录名必须与目标模组目录名完全一致
- 如果目标模组目录不存在，该补丁会被跳过
- 支持同时集成多个模组补丁，互不影响
